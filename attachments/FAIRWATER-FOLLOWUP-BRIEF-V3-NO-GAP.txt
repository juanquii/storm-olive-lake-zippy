## FIX-1 — Typecheck: trip rehydrate (.then on void)
FILE: src/components/fairwater/app.tsx (~lines 83–92)

CURRENT (broken):
```
useEffect(() => {
  void useTrip.persist.rehydrate().then(() => {
    if (useTrip.getState().helmMode === "leave") setSheet("open");
  });
  const saved = readLayout();
  setPanelPx(saved.panelPx);
  setSheet(saved.sheet);
  setLayoutReady(true);
  setLive(true);
}, []);
```

REQUIRED replacement behavior:
1. `const saved = readLayout();` FIRST — apply panelPx + sheet from saved layout.
2. Rehydrate without illegal `.then` on `void | Promise<void>`:
```
void Promise.resolve(useTrip.persist.rehydrate()).then(() => {
  // ONLY force sheet "open" for leave if there was NO saved layout preference
  // OR if saved.sheet was undefined. Never clobber an explicit saved "peek"|"closed".
});
```
3. Prefer:
```
useEffect(() => {
  const saved = readLayout();
  setPanelPx(saved.panelPx);
  setSheet(saved.sheet);
  setLayoutReady(true);
  setLive(true);
  void (async () => {
    await Promise.resolve(useTrip.persist.rehydrate());
    // do not override saved.sheet here
  })();
}, []);
```
4. When user taps Leave mode tab, you MAY setSheet("open"); when user taps Run, setSheet("peek") as today.

ACCEPTANCE FIX-1:
- [ ] `npm run typecheck` exits 0 (zero errors)
- [ ] Reloading with saved sheet "peek" keeps peek (not forced open)
- [ ] Leave tab still opens sheet when user selects Leave
