## 2. Bugs / polish that block “works perfect”

### P0 (ship blockers for Juan’s boat)

1. **Wrong boat defaults (FIXED this run).** Persisted bay-boat values were `tankGal: 40`, `draftFt: 1.5`, `burnGph: 8`, label “262 bay boat”. That understates range and draft for a Sportsman Open 262 and made fuel math meaningless.
2. **Gate hard-coded to Beaufort only.** Myrtle Beach / Little River / Masonboro / Bogue bars have no parallel gate profiles; Crystal Coast owner running south still sees “Beaufort Inlet run.”
3. **Blank chart / missing feeds in some builds.** QA screenshot `app-builder-built.png` showed empty map + Loading/No buoy; `inlet-check.png` worked with tiles + gale No-go. Fragile tile/WMS + buoy path under load or CORS.
4. **`npm test` script broken on Node 20.** `'scripts/**/*.test.mjs'` does not expand; `--experimental-strip-types` unsupported → auth/app-data tests never run in this sandbox.

### P1 (real-boat friction)

5. **Draft never enters gate or shoal logic** — display only; sandbar / inlet depth clearance not computed.
6. **No fuel range rings** on the map (only text RT math).
7. **No GPX / CSV export** for track or waypoints.
8. **Offline is tile-only.** Conditions/brief need network; last-good brief now helps NWS only.
9. **Mobile sheet collapses body text** (QA: mobile body 1651 → 331) — conditions peek mode hides the panel.
10. **`chartOn` in trip store is dead** — unused toggle.
11. **DMF HTML entity cleaner was a no-op** (FIXED: now decodes `&amp;` / `&#039;` / etc.).
12. **Waypoint cap 12 / track 400** — fine for day trips, short for multi-day or long troll tracks.
13. **Catch log has no edit/delete/export.**
14. **Persist migrate for trip forces outer-banks + beaufort-inlet** every version bump — can surprise travelers.

### P2 (polish)

15. Region id `outer-banks` labeled “North Carolina” (includes Cape Fear / Wrightsville — naming drift).
16. No Myrtle Beach / Little River / AR-series reefs / Radio Island pins.
17. No home marina pin for 70 West / Coral Bay.
18. Compass shows 0° when `deg` is null (arrow hidden, but rotation still 0).
19. Field inputs use `defaultValue` + `key={value}` — OK, but easy to lose mid-edit on remote patch.
20. Eight OG/PWA chrome unit tests failing (pre-existing platform chrome, not Fairwater marine logic).
