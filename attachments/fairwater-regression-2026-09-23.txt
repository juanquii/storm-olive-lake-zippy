# Fairwater masterpiece regression review — 2026-09-23

Reviewed `/workspace/user-upload-inspect` against `FAIRWATER-MASTERPIECE-GROK-BUILD-BRIEF-V2-NO-GAPS.md` and `CHANGELOG-masterpiece.md`. Scope: stores, marine libs, fairwater UI, changelog. `tsc --noEmit` confirms a single error (known).

---

## Blockers

1. **`app.tsx` ~L84 — typecheck fails on `rehydrate().then`**
   - `useTrip.persist.rehydrate()` is typed `void | Promise<void>`; calling `.then` is `TS2339`.
   - Also races layout: sync `readLayout()` / `setSheet(saved.sheet)` runs immediately, then async rehydrate can force `sheet` to `"open"` when `helmMode === "leave"`, clobbering a saved peek preference.

2. **`gpx.ts` `escapeXml` is a no-op (broken GPX 1.1)**
   - Body is literally `.replace(/&/g, "&").replace(/</g, "<").replace(/>/g, ">")` — does not emit `&amp;` / `&lt;` / `&gt;`.
   - Waypoint names with `&`, `<`, or `>` produce invalid / unsafe GPX. Epic F acceptance (“GPX opens in a second tool”) fails for non-trivial names.

---

## Major

1. **Run mode + mobile peek: Mark / Record unreachable**
   - Brief §3.2 wants map overlay chips for Mark · Record in Run.
   - `map.tsx` only overlays Whole coast / Save view / Range rings. Mark/Record live in `cruise.tsx` “Route and fuel” fold.
   - On mobile Run, `app.tsx` sets `sheet` to `"peek"` and hides panel body (`max-lg:hidden`). Operator cannot drop marks or start track without opening the sheet — core Run UX gap.

2. **`fairwater-gate-last` written, never read**
   - Epic D: airplane Leave should show last gate + brief with stale badge.
   - Brief/conditions caches are read; gate cache is write-only (`cruise.tsx`). Offline with mismatched inlet / empty conditions cache recomputes gate from nulls (always caution), not the last stored gate.

3. **Shellfish closures still Beaufort-centric**
   - `brief.ts` `loadClosures` keeps only `carteret|onslow`. Southern inlets (Cape Fear, Lockwoods, Little River / Myrtle) never surface relevant Brunswick / New Hanover / Horry closures.
   - Multi-inlet Leave/Fish trust regresses south of Bogue.

4. **Checklist hard-codes AMZ158**
   - `boat.ts` `CHECKLIST_ITEMS` nws label: `"NWS coastal waters (AMZ158) read"`.
   - Inlet switch updates zone in NWS fold, but checklist stays Beaufort-only wording.

5. **Fish mode: no explicit “best window” / “Legal to keep?” chip**
   - Bite score + reasons exist; `bestWindow` feeds `fishingRead` only — no dedicated best-window control above the fold.
   - Always-on “Check regs” link + calendar caveat present, but no amber per-species / uncertain “Legal to keep?” chip as brief §3.3 / Epic E require.

6. **Epic G buoy/tile 8s timeout → retry not implemented as specified**
   - Conditions/brief use 12–20s `AbortSignal.timeout`; geolocation uses 8s.
   - No dedicated buoy race timeout with map-level retry. Inlet has “Retry feeds” only when `isError && !conditions`.

## Minor

1. **Gate copy vs brief**: UI says “Under your limits” instead of “GO”; gate card uses border tint, not 56px color-fill block (§3.1).

2. **Home marina cannot be cleared to `null`**: select `value={boat.homeMarinaId ?? "70-west"}` always picks a marina; brief allows `null`.

3. **Coral Bay coords**: code `34.7, -76.767` vs brief `~34.72, -76.70` (acceptable but not the seed).

4. **DMF / catch empty states**: proclamations list renders nothing when empty (no “None loaded”); catch fold meta says Empty but list is blank — weak empty UX.

5. **Saved grounds tap targets**: `panel.tsx` saved rows use `h-11` (44px); rest of helm uses `h-12` / `min-h-12`.

6. **Double `useBoat.persist.rehydrate()`** in `app.tsx` and `cruise.tsx` — redundant, possible flicker.

7. **`OFFSHORE_RT_NM` alias equals one-way** (`boat.ts`) — deprecated correctly but easy to misuse if old call sites return.

8. **Night helm**: CSS meets brief (near-black, amber accents, tile dim). Gate semantic colors remapped under wash — still distinct enough; no further issue.

9. **Peek line defaults**: shows `"Fuel" · "Bite"` until custom events fire; brief expects gate+fuel+bite — OK after first CruiseBoard/panel paint, blank-ish on cold start.

10. **Inlet change always forces `setRegion("outer-banks")`** even if user was browsing another coast — surprising but ops-aligned.
